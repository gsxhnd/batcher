# batcher

基于 ffmpeg 的视频批处理工具，提供交互式终端界面（TUI）。支持视频转码、添加字幕、添加字体的任意组合——多个操作在同一条 ffmpeg 命令内一次完成，只处理一遍。

## 目录结构

```text
cmd/
  batcher/            TUI 入口
internal/
  commandline/        参数解析、引用与规范化，不调用 shell
  command/            命令规划（只读）：配置与操作组合（option.go / selection.go）、任务快照与命令生成（plan.go）、命令格式化（format.go）
  media/              输入输出扫描、路径规划与冲突校验
  task/               任务模型、状态机、串行队列与任务记录（model.go / queue.go / store.go / execute.go）
  ffmpeg/             只管进程：启动 ffmpeg 并转成事件（runner.go / probe.go / progress.go / event.go）
  testutil/           各包测试共用的临时占位文件
  presets/            转码参数预设：内置预设（builtin.go）+ 用户自定义预设读写（presets.go）
  tui/                Bubble Tea 交互式界面（model.go 状态与事件、panels.go 面板逻辑、modal.go 弹窗、views.go 渲染）
```

## TUI

基于 [Bubble Tea v2](https://github.com/charmbracelet/bubbletea) 的交互式终端界面：

```bash
go run ./cmd/batcher
```

界面为左侧五个面板 + 右侧内容区，不需要按向导逐页前进。按 `1`–`5` 或 `Tab` 切换面板；窄终端自动退化为单列，按 `?` 查看完整快捷键。

1. **[1] 操作**：`space` 勾选视频转码 / 添加字幕 / 添加字体，至少一项。
2. **[2] 转码预设**：勾选转码后可用。`Enter` 使用预设；`a` 复制内置预设或新增自定义预设；`e` 编辑、`d` 确认删除自定义项；`J` / `K` 调整自定义项顺序。手动参数在面板 [4] 编辑。
3. **[3] 字幕轨道**：`n` 新增、`e` 编辑、`d` 删除；指定后缀、ISO 639-2 三字母语言码（`chi` / `eng` / `jpn` 等）和标题；`t` 切换默认字幕，同一时间至多一条默认轨道。
4. **[4] 参数**：`Enter` 进入编辑，`Tab` / ↑ / ↓ 切换字段，`Esc` 完成。支持粘贴路径与长参数；`Ctrl+S` 把高级参数另存为自定义预设。输入期间普通字符不会触发全局快捷键。
5. **[5] 任务**：配置变化后自动防抖生成命令。↑ / ↓ 切换文件；`y` 复制所选命令（“全部”复制所有命令）；`PgUp` / `PgDn` / 滚轮滚动。按 `x` 或 `Enter` 把当前配置加入任务队列，队列空闲时立即开始执行；同一时刻只运行一个 ffmpeg 子任务。

预设/字幕的编辑弹窗内：`Tab` / `Enter` 循环推进字段（`Enter` 不做确认），`Ctrl+S` 保存，`Esc` 取消；底部有按键提示。删除等确认弹窗仍是 `Enter` 确认 / `Esc` 取消。

执行期间继续编辑配置即入队新批次并将任务面板切回命令预览；入队后任务面板显示**队列视图**：主任务列表（状态+进度概要），`enter` 展开可见每个子任务的状态与命令，`y` 复制命令（批次行=整批命令），右侧置顶始终显示光标所在子任务的完整命令（不管它是否正在执行）；完成后仍可逐个子任务查看状态、错误尾部与命令。子任务失败时队列暂停并**冻结计时**（提示“已暂停”），按 `r` 重试 / `s` 跳过 / `a` 中止当前主任务；`q` / `Esc` 取消当前批次（剩余子任务标为取消），队列随后继续处理下一个批次。失败或取消的子任务只保留已完成的成品，半成品输出文件会被删除。`Ctrl+C` 退出前会停止队列、取消当前命令并等待任务记录落盘。

### 规划与执行约定

- **预览不写入文件、不创建目录，也不调用 ffmpeg**；执行使用预览中的任务快照，不重新扫描目录。
- 视频递归扫描，自动排除独立的输出子目录；输入后缀不区分大小写。同名视频分配唯一输出路径，拒绝输出与输入文件重合。
- 字幕在**各视频所在目录**查找，精确的 `<视频名>.<后缀>` 优先，其次接受唯一的 `<视频名>.<标记>.<后缀>`。缺失或多个候选会在预览中报错；多语言请使用 `chi.ass` / `eng.ass` 等完整后缀。
- 所有输入先于输出编码参数。默认保留原视频的全部流；添加字幕时新增字幕排在原字幕之前，语言、标题与默认标记不会误写到原字幕。
- 高级参数是**输出侧选项**，支持单/双引号和转义，保留引号内的空白；不展开变量、通配符或命令替换，不经 shell 执行。路径含空格时请加引号，Windows 路径建议使用单引号。
- **已有输出文件一律报错，不覆盖**，高级参数不接受 `-y`、`-stdin` 或额外的 `-i`。需要重跑时先移动已有结果或更换输出目录。
- 任务在队列中按顺序执行，同一时刻只运行一个 ffmpeg 进程；主任务按入队顺序依次执行，失败的也不阻塞后续主任务。子任务失败或取消会删除半成品输出（`-n` 保证不会误删已有成品），继续处理其余子任务。取消后可能保留部分输出文件，不会自动删除，请检查后再重跑。
- 复制的命令在 macOS / Linux 使用 POSIX shell 引用，在 Windows 使用 PowerShell 引用。

## 预设存储

- 内置预设：随程序内置（代码 `internal/presets/builtin.go`），只读，包含 H.264/H.265、NVIDIA 与 Apple VideoToolbox 硬件加速、无损封装等常用参数。
- 自定义预设：保存在 **CLI 可执行文件所在目录下的 `presets/` 文件夹**（`advance_presets.json`），保存时自动创建，随分发的可执行文件走，便于便携使用。
- 环境变量 `BATCHER_PRESETS_DIR` 可覆盖预设目录（开发、测试或特殊部署时使用）。

## 测试

```bash
go build ./...
go vet ./...
go test -race ./internal/... ./cmd/batcher/...
gofmt -l internal cmd
```

ffmpeg 相关测试需要本机已安装 `ffmpeg` 和同套发行版的 `ffprobe`。命令单元测试使用临时占位文件；集成测试运行时生成微型媒体，覆盖全部七种操作组合、双音轨保留、原有字幕元数据、字体附件及防覆盖行为。所有文件均在临时目录生成，无需准备仓库内 testdata。

ffmpeg 常用参数速查见 [docs/ffmpeg.md](docs/ffmpeg.md)。
