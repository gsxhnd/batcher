# batcher

基于 ffmpeg 的视频批处理工具，提供交互式终端界面（TUI）。支持视频转码、添加字幕、添加字体的任意组合——多个操作在同一条 ffmpeg 命令内一次完成，只处理一遍。

## 目录结构

```text
cmd/
  batcher/            TUI 入口
internal/
  commandline/        参数解析、引用与规范化，不调用 shell
  command/            命令规划（只读）：配置与操作组合（option.go / selection.go）、任务快照与命令生成（plan.go）、命令格式化（format.go）
  media/              输入输出扫描、路径规划与冲突校验
  task/               任务模型、串行队列与执行（model.go / queue.go / store.go / execute.go）
  store/              bbolt 数据库：任务与自定义预设（store.go）
  ffmpeg/             只管进程：启动 ffmpeg 并转成事件（runner.go / probe.go / progress.go / event.go）
  testutil/           各包测试共用的临时占位文件
  presets/            转码参数预设：内置预设（builtin.go）+ 读写接口（presets.go）
  tui/                Bubble Tea 交互式界面（左右任务列表、创建弹窗、预设管理）
```

## TUI

基于 [Bubble Tea v2](https://github.com/charmbracelet/bubbletea) 的交互式终端界面：

```bash
go run ./cmd/batcher
```

界面直接分成左右两侧：左侧是任务列表，右侧是当前任务的状态、命令和日志。窄终端改成上下排列。按 `?` 查看完整快捷键。

- **`a` 新建任务**：打开一个居中的分区弹窗，后面的主界面会压暗，按键和滚轮都留在弹窗里。可勾选视频转码、添加字幕、添加字体，并填写路径、转码预设、高级参数和字幕。弹窗里没有分步。`Enter` 移到下一项，最后一项或 `Ctrl+S` 创建；`Ctrl+N` 再加一组字幕，`Ctrl+D` 删掉当前组。字幕语言用 ISO 639-2 三字母码（`chi` / `eng` / `jpn`），最多一条默认字幕。创建后加入队列；如果正在执行，新任务排在当前任务后面。同一时刻只运行一个 ffmpeg 子任务。
- **`p` 转码预设**：列表来自数据库，每一条都可以 `e` 编辑、`d` 确认删除，`J` / `K` 调整顺序。`a` 从空白表单新建，`c` 复制当前这一条。第一次使用、数据库里还没有预设时，会写入一套内置预设；之后以数据库为准，删掉的不会再自动加回来。保存或取消后回到这个列表。

任务列表里 ↑ / ↓ 选择，`Enter` 展开或收起子任务和每一次尝试，`y` 复制光标所在命令，`f` 跳回正在执行的子任务。右侧始终显示光标那一条的完整命令。子任务失败时队列暂停并**冻结计时**，按光标位置：`r` 重试，`s` 跳过，`x` 中止。主任务行 `r` 重试整个任务（已结束或历史任务会把失败项重新排队），`d` 从列表和数据库删除。执行中 `q` / `Esc` 取消当前批次；暂停时 `q` / `Esc` 中止。执行过程中仍可以按 `a` 再建一个主任务，它会等当前任务结束后再开始。失败或取消的子任务只保留已完成的成品，半成品输出文件会被删除。`Ctrl+C` 退出前会停止队列、取消当前命令并等待记录落盘。

### 规划与执行约定

- **预览不写入文件、不创建目录，也不调用 ffmpeg**；执行使用预览中的任务快照，不重新扫描目录。
- 视频递归扫描，自动排除独立的输出子目录；输入后缀不区分大小写。同名视频分配唯一输出路径，拒绝输出与输入文件重合。
- 字幕在**各视频所在目录**查找，精确的 `<视频名>.<后缀>` 优先，其次接受唯一的 `<视频名>.<标记>.<后缀>`。缺失或多个候选会在预览中报错；多语言请使用 `chi.ass` / `eng.ass` 等完整后缀。
- 所有输入先于输出编码参数。默认保留原视频的全部流；添加字幕时新增字幕排在原字幕之前，语言、标题与默认标记不会误写到原字幕。
- 高级参数是**输出侧选项**，支持单/双引号和转义，保留引号内的空白；不展开变量、通配符或命令替换，不经 shell 执行。路径含空格时请加引号，Windows 路径建议使用单引号。
- **已有输出文件一律报错，不覆盖**，高级参数不接受 `-y`、`-stdin` 或额外的 `-i`。需要重跑时先移动已有结果或更换输出目录。
- 任务在队列中按顺序执行，同一时刻只运行一个 ffmpeg 进程；主任务按入队顺序依次执行，失败的也不阻塞后续主任务。子任务失败或取消会删除半成品输出（`-n` 保证不会误删已有成品），继续处理其余子任务。取消后可能保留部分输出文件，不会自动删除，请检查后再重跑。
- 复制的命令在 macOS / Linux 使用 POSIX shell 引用，在 Windows 使用 PowerShell 引用。

## 数据存储

任务和自定义预设都写在 **可执行文件所在目录的 `batcher.db`**（[bbolt](https://github.com/etcd-io/bbolt)），和程序放在一起，拷走可执行文件时把这个文件一并带走。环境变量 `BATCHER_DATA_DIR` 可改这个目录。

- 内置预设：第一次打开数据库且还没有预设记录时写入 `batcher.db`。记录已经存在就不再插入，所以删掉或改过的预设会保留。
- 第一次打开数据库时，如果可执行文件目录下还有旧的 `presets/advance_presets.json`，会导入一次。之后以数据库为准。
- 输出目录只在任务真正执行时创建。规划阶段不写文件、不建目录、也不调用 ffmpeg。

## 测试

```bash
go build ./...
go vet ./...
go test -race ./internal/... ./cmd/batcher/...
gofmt -l internal cmd
```

ffmpeg 相关测试需要本机已安装 `ffmpeg` 和同套发行版的 `ffprobe`。命令单元测试使用临时占位文件；集成测试运行时生成微型媒体，覆盖全部七种操作组合、双音轨保留、原有字幕元数据、字体附件及防覆盖行为。所有文件均在临时目录生成，无需准备仓库内 testdata。

ffmpeg 常用参数速查见 [docs/ffmpeg.md](docs/ffmpeg.md)。
